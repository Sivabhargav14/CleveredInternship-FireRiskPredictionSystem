## About my App

My app/project uses Random Forest Classifier Model to analyse parameters such as temperature, pressure, humidity and particulate 
concentrations. Based on these inputs, the application predicts the fire risk level with audio alerts.

## How to use the App

1) Launch the application.
2)Enter the required sensor values into the input boxes. 
3)Click the “Predict Fire Risk” button. 
4)Observe the fire risk probability and risk classification.
5)Listen to the generated voice alert.

#The system then predicts fire risk and provides both visual and audio alerts based on environmental sensor inputs.
